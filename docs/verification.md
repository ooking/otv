# 回归与排障

测试前先用几句话说明改动范围、测试设备、将执行的步骤和预期结果，得到同意后再执行。仓库当前没有独立的自动化测试源码，涉及硬件的回归依赖开发电视。验证记录写明设备型号、Android 或固件版本、使用的频道或节目源，以及实际结果。

## 按改动选取回归场景

| 改动 | 操作与预期 |
| --- | --- |
| 频道与生命周期 | 授权并加载频道，切到另一台后退到后台再进入。确认恢复上次成功播放的频道，过渡层退出，离开前台时释放播放会话。 |
| 导航与焦点 | 遥控器打开频道栏、指南和选项，操作方向键后逐层返回。确认焦点可见且回到原位置，浏览频道栏时继续播放，按确认后才切台。 |
| 节目指南与缓存 | 打开指南，检查正在播、未来节目和无数据时段。导入覆盖现有频道的 XMLTV 样本，确认展示时段正确，系统资料优先，重启应用后仍可读取未到期节目。 |
| XMLTV 异常输入 | 使用无匹配频道、非法时间或无法下载的样本，确认界面给出结果，已有节目仍能读取。调整合并时另覆盖同一节目补简介和系统覆盖缩小的场景。 |
| 音轨、字幕与兼容音频 | 选有相应轨道的频道，切换轨道并换台后返回，确认字幕偏好能按频道恢复。修改小米兼容时用同一频道对照开关、切台和退后台，现场确认声音与行为。 |

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 提示未发现调谐器 | 检查电视型号和 `dumpsys tv_input` 中的输入，与 `TvListings.INPUT_ID` 对照。 |
| 原生直播有频道但 OTV 为空 | 检查电视节目权限、原生 DTMB 搜台结果和 `DtmbListings` 日志。固件可能只向第三方应用公开部分记录。 |
| 指南只有当前节目或少数频道 | 检查 `DtmbGuide` 中系统查询的覆盖数量。XMLTV 无匹配时核对 `display-name`、节目时间范围、时区偏移（如 `+0800`）和电视时间。 |
| 在线导入失败 | 检查节目源是否能从电视直接访问、是否返回 HTTP 200、内容是否为 XML 或 gzip。 |
| 有画面但无声音 | 检查电视媒体音量和菜单里的「音频诊断」。在支持的小米开发电视上，可用同一频道对照「小米音频兼容」开关。 |
| 字幕样式设置没有影响 | DTMB 广播字幕通常由固件渲染，样式由广播及固件决定。用菜单检查当前频道是否向应用提供字幕轨。 |

在获批的开发电视上采集日志。替换 `TV_SERIAL`，共享输出前移除设备标识和带访问凭据的地址。

```sh
adb -s TV_SERIAL logcat -d -s DtmbPlayback:I DtmbListings:I DtmbGuide:D
adb -s TV_SERIAL shell dumpsys tv_input
adb -s TV_SERIAL shell dumpsys audio
adb -s TV_SERIAL shell dumpsys media.audio_flinger
```

系统日志能帮助定位焦点、会话和静音状态，实际音频输出以电视现场听到的结果为准。
